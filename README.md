Lantern Harbor is an original spot-the-difference game set in the invented harbor town of Pell Harbor at three times of day. Every scene is painted procedurally with Canvas 2D and drawn twice from one set of variant flags, so the two panels can differ only where a difference declares it: 7 differences at dawn, 9 at market noon, 11 at lantern dusk, growing subtler as the light fades. Clicks ring both panels with a synthesized pop, wrong clicks cost time, hints are limited, and a countdown keeps the pressure on. No libraries, no network, no image files — just vanilla JS split into single-job modules. To play locally: `node serve.ts` and open the printed address.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
